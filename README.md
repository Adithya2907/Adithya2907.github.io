# Adi — Personal Site

Static personal website for Adi, published with GitHub Pages from the `dist/` directory.

The account-site repository is named `Adithya2907.github.io`, so the site is served at the root of `https://adithya2907.github.io` and the site's root-relative asset URLs work as written.

## Local preview

```sh
python3 -m http.server 4173 --directory dist
```

Pushes to `main` deploy the current `dist/` files to GitHub Pages. There is no custom domain configured.
